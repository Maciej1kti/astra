# Start here

Read [README](README.md) for the product and [Contributing](CONTRIBUTING.md) before
changing code. [Code structure](docs/CODE-STRUCTURE.md) describes maintained module
ownership. [Current status](progress/STATE.md) distinguishes implementation from
release acceptance.

The [documentation index](docs/README.md) identifies contracts and retained
requirements. Owner decisions in [scope](progress/SCOPE.md) take precedence over
the historical handoff. Do not initialize a new application skeleton: this
repository already contains the working daemon, CLI and browser application.
