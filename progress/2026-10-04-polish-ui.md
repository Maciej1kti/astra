# Polish browser interface — 2026-10-04

The owner requested Polish text throughout the browser, keeping Focus. The
implementation covers navigation, all views, card/project/report editors,
settings, registration/pairing, diagnostics, conditional-save recovery and
accessibility announcements. Native Board/Timeline and Calendar words, dates,
numbers and counter summaries use Polish presentation; chart rates accept comma
or point. Source data and CLI/protocol identifiers are preserved.

The browser presents Polish even with an English browser locale or a stored
English workspace preference. Saving settings records the Polish locale; simply
opening the application does not rewrite preferences. User-authored titles,
descriptions, units and profile names retain their original content. Detailed
server messages and additional screens/dialogs load on demand to retain the
existing 80 KiB initial gzip budget.
