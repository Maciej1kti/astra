# Shared Astra UI system

Implemented the approved light visual direction across Focus, Projects, Board,
Calendar, Timeline, List, Updates and resource details, including auxiliary
dialogs and the pairing screen. Dark/system appearance remains supported.

Visual values now live in `styles/tokens.css`. Small shared Svelte components
own buttons, badges, icons, branding, headings, empty states, resource cards and
metadata. Workspace screens compose these without local CSS or inline visual
values. Native form and gesture controls share the same tokens; numeric vendor
timeline dimensions have a single configuration. No dependencies were added.

The card checklist uses one compact panel, progress count, inline text editing,
native checkboxes and 44px remove/reorder targets. Pointer, touch, keyboard,
validation and autosave behavior are preserved. Mobile navigation exposes every
view, filters wrap, and calendar/board/timeline scrolling stays within the view.
The calendar width collision found during visual review is fixed and covered by
a browser assertion.
