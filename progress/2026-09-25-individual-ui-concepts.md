# Individual desktop and mobile UI concepts — 2026-09-25

The owner requested separate generations after the combined concept board and
explicitly selected eight views / sixteen graphics, adding Card details to
Focus, Project, Board, Calendar, Timeline, List and Updates.

Created sixteen independent built-in ImageGen outputs: one desktop and one
mobile image per view. These are newly composed screens, not crops of the
earlier board. The shared reference direction uses white/pale-gray surfaces,
subtle depth, charcoal controls and blue selection. Content is illustrative.

Every generated screen was visually reviewed. Mobile Focus now includes its
utility footer, Board shows horizontally adjacent columns, Calendar uses an
agenda, Timeline keeps a time axis, and Card details retains description,
Start/End, compact checklist and autosave presentation.

Raster limitations remain: logo/icon and badge variations, some generated
affordances, mobile Calendar's omitted Add-card control, and its desktop
Focus-task continuation extending one day beyond the sample end date. The
images are visual proposals, not exact data or behavioral specifications.
The detailed review is included with the artifacts.

Deliverables are in ignored `test-results/ui-design-2026-09-25/screens/`:
sixteen PNGs, sixteen exact prompts, a local gallery, index/notes, an inventory
with dimensions and hashes, and a ZIP. Verification checks file count, PNG
headers, desktop/mobile orientations, uniqueness, local gallery references
and ZIP integrity. No application code, project scope, priority, status or
acceptance changed; no browser/device or release acceptance is claimed.
